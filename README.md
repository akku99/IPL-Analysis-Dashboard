# 📊 IPL Analysis Dashboard 🏏 | Power BI Project

## 📌 Project Overview

The IPL Analysis Dashboard is an interactive Power BI project designed to analyze historical Indian Premier League (IPL) data and uncover insights related to team performance, player statistics, match outcomes, venue trends, and toss decisions.

This dashboard enables users to explore IPL data through dynamic visualizations, filters, and key performance indicators (KPIs), helping cricket enthusiasts, analysts, and stakeholders make data-driven observations about tournament trends.

## 🎯 Business Problem

The IPL generates a vast amount of match and player data every season. Extracting meaningful insights manually is difficult and time-consuming.

This dashboard aims to:
-Analyze team and player performance across seasons.
-Identify winning patterns and trends.
-Evaluate the impact of toss decisions on match outcomes.
-Compare team performances at different venues.
-Provide an interactive platform for IPL data exploration.

## 📊 Dashboard Features
1. Tournament Overview
  -Total Matches Played
  -Total Teams Participated
  -Total Seasons Covered
  -Overall Win Statistics
  -Interactive Filters

2. Team Analysis
  -Team-wise Matches Played
  -Win Percentage Analysis
  -Home vs Away Performance
  -Season-wise Team Comparison

3. Player Analysis
  -Top Run Scorers
  -Most Sixes
  -Most Fours
  -Leading Wicket Takers
  -Best Batting Performances

4. Season Insights
  -Season-wise Champions
  -Match Trends by Year
  -Performance Evolution Across Seasons
